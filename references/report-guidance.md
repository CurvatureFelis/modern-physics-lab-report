# LaTeX 报告与交付规范

仅在生成或审校报告时读取。

- 实验原理重组用户材料，保留支撑数据处理所需的推导、假设与适用条件；压缩无关理论。
- 仪器与步骤只写材料明确提供的内容。未知型号、精度和操作不得补写。
- 原始数据完整呈现；数据量很大时可给代表性分页表，但须明确完整机器可读表路径。不可只给处理后数据。
- 数据处理展示足以复核的公式、一个代表性计算链路、拟合方法及结果，不把整段代码粘进正文。
- 误差分析引用实际仪器、残差、参数不确定度、漂移或实验条件，直接给出误差来源、影响方向和结果结论；禁止空泛套话，也不写资料缺失清单。
- 讨论评价模型符合度、残差结构、理论值差异、随机或系统误差、方法局限与可操作改进，不重复结论。

## 原理的完整性

以资料的深度校准报告的深度。若教师资料详细给出量子或经典图像、核心运动方程、近似条件、仪器响应和测量序列，报告应把这些内容重组为一条完整逻辑链：研究对象与平衡态 → 外场作用与可观测信号 → 测量序列如何隔离目标物理量 → 拟合模型及变量含义 → 适用条件和主要偏离机制。篇幅可以比普通模板长，但每段必须服务于实验理解或数据分析。

不要把“原理写详细”等同于整段照抄讲义。删除重复叙述和与本任务无关的历史材料；保留并解释后续公式、作图、拟合和误差分析真正依赖的部分。若资料存在不同约定，指出差异并说明本报告采用哪一种，不能静默拼接。

分析脚本应生成 `data/processed/` 派生量与审计表、`report/generated/results.tex` 关键标量宏、`report/generated/tables/*.tex` 表格、`figures/` 图像和 `analysis/results.json` 机器可读结果。正文通过 `\input{}`、宏和 `\includegraphics{}` 引用，不重复手输结果。

## 图像、截图与矢量重绘

先区分资料图与实验记录图。实验照片或软件拟合界面中的数据、坐标和关键标注明显清楚时，直接裁切并插入报告 PDF，以保存原始显示信息；同时保留未经修改的原图。若缩放后数值、曲线或标注不清，再依据可辨内容重绘。存在机器可读原始数据时，数据点、拟合曲线、误差棒和残差图仍由分析脚本生成。

资料中的实验装置照片、复杂结构或软件界面在内容清楚且确有说明价值时可以裁切插入。保留未经修改的源文件，并在项目内部审计记录中写明文件、页码或图号以及裁切、旋转、对比度调整等处理；裁切只用于去除无关边缘，不得删去会改变解释的比例尺、坐标、图例、警示或关键连接。正式图注只描述图中对象、变量、实验条件和必要的物理含义，不写来源或制作过程。

当原图分辨率不足、线条和符号不清，或示意关系需要精确排版时，使用 TikZ、PGFPlots、circuitikz 或 Python 重绘。重绘必须忠于资料中的拓扑、方向、时序、坐标和符号，不凭空增加器件或实验事实。图注直接写图中对象、变量、条件和必要物理含义，不写“根据……重绘”“非实验波形”“非实验数据”“来源于……”等制作说明。图像真实性与重绘范围保留在内部审计记录中。优先重绘脉冲序列、矢量图、简单光路/电路和理论函数；清晰实验数据截图与真实仪器外观优先保留。

## 正式报告语言与来源

数据处理章节只保留实验计算和拟合本身：模型、变量、数据范围、权重、参数、必要的不确定度和残差判断。脚本文件名、目录、哈希、转录步骤、AI 操作、自动回填与工程流水线属于项目实现信息，不写进正式报告正文。

正文采用客观实验报告语气，直接写物理内容，不出现“根据讲义/资料/图片”“依据某材料”“不能作为正式报告”“不能作为某依据”“用户提供”“AI 处理”等来源提示、制作过程或对话话术。把当前实验材料视为实验者能够获得的完整记录，不在报告中写“尚缺数据”“未上传”“有待补充”“需要更多数据后”等材料完整性说明。证据边界通过结论强度表达：能够定量时报告数值，不能定量时只给有物理依据的定性结论；不得编造不确定度、仪器精度或残差。

## 不确定度与误差分析写法

本节从结论起笔，不复述数据收集过程。优先写：已得到的拟合不确定度或重复性指标；偏差最大的参数或数据结构；仪器分辨率、零点、漂移、场不均匀、接触电阻、光路调节、脉冲标定等具体机制；每种机制会使目标量偏大、偏小或增加离散；这些因素是否改变实验结论。若没有可计算的 A 类、B 类或合成不确定度，只写实际可判定的误差方向和稳健性结论，省略数值预算。禁止用“因缺少……无法计算”“待补充……”填充本节。

资料来源仅列具有明确书名、讲义名、课件名、论文题名或标准号的资料，不列“用户提供的图片/论文/附件”。实验照片和软件界面属于原始实验记录，在原始数据章节或图注中标注即可。

所有插图应具有可读轴名、单位、图例和必要标注，缩放到正文尺寸后仍清楚，并在黑白打印下能区分。编译后逐页检查图中文字、浮动位置、裁切边界和交叉引用。

使用 XeLaTeX 处理中文，推荐 `ctexart`、`amsmath`、`siunitx`、`booktabs`、`graphicx`。物理量用数学斜体，单位用正体并由 `siunitx` 排版。长表使用 `longtable` 或拆表，不缩到不可读。

## 符号规范

公式与正文符号以 `$latex-symbol-conventions` 当前版本及其版本化权威参考为准。写作前检查项目中已有的 `rynotes_*.sty` 或其他本地样式：版本化规范决定符号含义和字体，本地样式决定可用命令。优先复用已有语义宏，不重复定义同义命令；没有本地样式时才使用报告模板提供的最小兼容宏。

按语义区分标量与粗斜体向量/矩阵、经典量与带帽量子算符、斜体变量与正体常数/算子/描述性下标。全文统一希腊字母变体和同一物理对象的记法。不要在报告正文中加入“已遵守符号规范”等元叙述，除非用户要求符号表或规范说明。

```text
latexmk -xelatex -interaction=nonstopmode -halt-on-error report.tex
```

编译成功后把 PDF 渲染为图片逐页检查标题、公式、表格、图例、浮动位置、越界和缺字，再按 `$latex-symbol-conventions` 审计符号语义与一致性。最终核对关键数字可追溯、原始表与处理表分开、单位和有效数字一致、不确定度假设明确、异常点未被静默删除，且结论不超出数据支持范围。报告不得包含面向上传完整性的缺失信息清单。

最终 PDF 通过检查后，使用 Skill 的 `scripts/cleanup_lab_project.py` 先扫描再删除项目中的允许项临时文件。清理属于交付收尾，不得发生在最终编译或视觉检查之前；清理后再次确认最终 PDF、源文件、数据和结果仍存在。
