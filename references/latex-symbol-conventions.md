# 近代物理实验报告 LaTeX 符号规范

本文件是 Skill 的自包含最低规范。若环境中存在 `$latex-symbol-conventions`，应再读取其当前版本化权威参考；本文件保证未安装外部 Skill 时仍可一致排版实验报告。用户或课程明确规定的项目级约定优先。

## 基本规则

- 标量、普通变量和物理量使用数学斜体，如 `x`、`t`、`T_1`、`T_2`。
- 向量、矩阵和以分量参与运算的张量使用粗斜体 `\bm{}`，包括希腊字母向量；不要用 `\mathbf` 排希腊向量。
- 量子力学算符使用帽号，如 `\hat{H}`、`\hat{S}_z`；态使用 `\ket{\psi}`，不加帽、不加粗。
- 数学常数、算子名、文字标签和描述性上下标使用正体。自然常数与虚数单位分别写作 `\mathrm{e}`、`\mathrm{i}`；描述性下标写作 `T_{\mathrm{eff}}`。
- 数值与单位使用 `siunitx`，如 `\SI{20}{\mega\hertz}`、`\qty{6.3}{\milli\second}`。单位不使用数学斜体，也不手工拼接空格。
- 积分微元采用正体 `\mathrm{d}`，导数中的微分符号保持一致；若模板提供 `\dd`、`\ddd` 等语义宏则优先使用。
- 同一物理对象在全文保持一个符号和一个希腊字母变体。不要交替使用 `\phi`/`\varphi` 或 `\epsilon`/`\varepsilon`。

## 实验报告常用约定

- 测量值与不确定度写作 `x=(x_0\pm u_x)\,\si{unit}`，数值位数与不确定度末位对齐。
- 平均值用 `\bar{x}`，标准不确定度用 `u(x)`，合成标准不确定度用 `u_{\mathrm c}`；下标 `\mathrm c` 为描述性标签。
- 差值、变化量使用大写 `\Delta`，不要与 Dirac delta、Kronecker delta 或变分符号混写。
- 拟合参数首次出现时定义其物理意义和单位。斜率、截距等普通参数保持斜体；参数估计量仅在统计语境明确时使用帽号。
- 指数衰减写作 `A\mathrm{e}^{-t/\tau}` 或模板语义宏 `A\ee^{-t/\tau}`；指数底必须正体。
- 频率 `\nu`、角频率 `\omega`、弛豫时间 `T_1`、`T_2`、`T_2^*` 等在首次出现时定义，并避免同一符号承担两个未消歧的物理含义。
- 电磁场、磁化强度和角动量等向量使用粗斜体，如 `\bm{B}`、`\bm{M}`、`\bm{J}`；若表示相应量子算符，再加帽号。
- Dirac 记号使用 `\bra{}`、`\ket{}`、`\ip{}{}`、`\mel{}{}{}`；算符在矩阵元中仍保留帽号。

## 审计清单

交付前逐项检查：

1. 标量与向量/矩阵是否发生字体漂移。
2. 量子算符是否遗漏帽号，态是否被错误加帽或加粗。
3. `e`、`i`、微分、单位和描述性上下标是否误用斜体。
4. `\phi`/`\varphi`、`\epsilon`/`\varepsilon` 等变体是否前后不一致。
5. 同名符号是否因学科语境产生冲突，是否已用上下标、帽号或文字定义消歧。
6. 数值、单位、有效数字与不确定度末位是否一致。
7. 模板中使用的语义宏是否实际由本地样式或导言区定义。

编译成功只证明语法可用，不能替代上述语义检查。
