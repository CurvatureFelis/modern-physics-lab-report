# 图片数据转录规范

仅当实验数据存在于照片、手写表格、仪器屏幕或软件拟合界面中且没有等价的机器可读原始文件时使用本入口。原图完整保存在 `data/raw/`；转录结果写入 `data/processed/manual_transcription.csv`，不得覆盖、裁改或替代原图。

固定字段如下：

| 字段 | 含义 |
|---|---|
| `record_id` | 当前项目内唯一的记录编号 |
| `sample_id` | 样品、测量组或对象编号；不适用时留空 |
| `quantity` | 物理量名称或符号 |
| `value` | 按原图抄录的数值，不在此列换算或修约 |
| `unit` | 原图明确给出的单位；未显示时留空 |
| `condition` | 对应的实验条件、控制量或测量序列 |
| `source_file` | `data/raw/` 下的原始图片相对路径 |
| `source_region` | 页码、表格行列、屏幕区域或其他可复核定位 |
| `verification_note` | 核对状态及必要说明，如“双人核对”或“字符边缘模糊” |

## 转录流程

1. 先复制未经修改的图片到 `data/raw/`，再登记相对路径。
2. 一行只记录一个观测值或一个软件直接输出的拟合结果；不得从曲线目测补造坐标点。
3. 数字、正负号、小数点、科学计数法、单位和样品编号逐项核对。不能可靠辨认的单元格留空，并在 `verification_note` 记录位置，不猜测。
4. 软件界面直接给出的拟合值应在 `quantity` 中写明对应参数，例如 `T_2` 或 `T_2^*`；截图中的拟合点只有在数值清晰可读时才逐点转录。
5. 单位换算、有效数字处理、异常值判断和派生计算在分析脚本中完成，不修改本表的原始转录值。
6. 分析脚本读取本表后，应将其与机器可读数据一样纳入缺失值、重复记录、单位和条件对应关系检查。

正式报告只呈现物理数据、处理和结论，不描述转录流程。文件定位、识别疑点和图像处理范围保留在项目内部审计记录中。
